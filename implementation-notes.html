Bugs found & fixed during verification

  • ensure_allowed returned "deny" from a stored rule without raising → writes still executed. Fixed to raise PermissionDeniedError on any deny.
  • GBK console crashed on ⟳/✓/Chinese output → force UTF-8 stdio.
  • Lone surrogates from mid-stream UTF-8 splits crashed JSON dump / model request → clean at model-parse and session-save boundaries; also reconfigure stdin.
  • Non-interactive renderer bypassed the config deny default → fall through to config default when renderer is not interactive.
  • Session-id collisions within the same clock tick → add UUID suffix.

v2 扩展：桌面 GUI（2026-08-05）

项目已推送到 GitHub：github.com/lambda0302/pyagent（公开）。随后实现了桌面 GUI，全部通过无头测试与真实模型 E2E。

  • 新增 src/pyagent/gui/：renderer.py（GUIRenderer，实现现有 renderer 协议，事件推队列 + 权限/diff 阻塞确认）、server.py（stdlib ThreadingHTTPServer + SSE，端点 /api/health|stream|chat|permission|diff|sessions|resume|new）、app.py（pywebview 原生窗口 + --browser 回退）、static/（Codex 风格暗色前端：聊天流式、工具卡片、权限/diff 弹窗、会话侧边栏）。
  • CLI 接入：pyagent gui [--browser|--config|--cwd|--port]（首 token 嗅探，不破坏 pyagent "prompt"）。
  • 依赖：gui extra 新增 pywebview；后端零新依赖（纯标准库）。
  • 并发模型：主线程跑 webview 事件循环；agent 线程跑 AgentLoop；权限/diff 由 threading.Event 阻塞、前端 POST 解除，超时兜底。
  • 测试：tests/test_gui.py 10 例（渲染器单测 + urllib 服务端集成 + SSE 权限批准 E2E + 并发 409），全部无头可跑。
  • 真实模型 E2E：事件序列 snapshot→assistant_delta→tool_start(write)→permission→tool_result→tool_start(bash)→permission→tool_result→final→run_end，文件正确写入。
