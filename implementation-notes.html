Bugs found & fixed during verification

  • ensure_allowed returned "deny" from a stored rule without raising → writes still executed. Fixed to raise PermissionDeniedError on any deny.
  • GBK console crashed on ⟳/✓/Chinese output → force UTF-8 stdio.
  • Lone surrogates from mid-stream UTF-8 splits crashed JSON dump / model request → clean at model-parse and session-save boundaries; also reconfigure stdin.
  • Non-interactive renderer bypassed the config deny default → fall through to config default when renderer is not interactive.
  • Session-id collisions within the same clock tick → add UUID suffix.
